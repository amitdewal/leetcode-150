## My Problem-Solving Approach

For every problem, I try to follow this process:

1. **Understand the problem:** Identify inputs, outputs, and constraints.
2. **Identify the pattern:** Recognize whether the problem involves HashMap, Two Pointers, Sliding Window, etc.
3. **Think of brute force:** First understand the straightforward solution.
4. **Optimize:** Find a better approach using suitable data structures and algorithms.
5. **Dry run:** Execute the logic manually with sample inputs.
6. **Implement:** Write clean Java code.
7. **Analyze complexity:** Understand time and space complexity.
8. **Revision:** Revisit problems to improve speed and understanding.
